## Changelog

### 1.0.0 — Initial Release

- Core FSE templates: `index.html`, `home.html`, `page.html`,
  `single.html`, `search.html`, `404.html`
- Template parts: `header.html`, `footer.html`, `post-meta.html`
- Pattern library with 12 categories
- Style variations: Default, Cyberpunk Neon, Emerald Dark, Ocean Trust
- Self-hosted fonts: Inter, Plus Jakarta Sans
- Zero plugin dependencies — built on WordPress core and FSE

## Contributing

Iftin is open source and contributions are welcome.

### How to Contribute

- **Bug reports** — Open an issue on [GitHub](https://github.com/amiinmaalik/iftin/issues)
- **Feature requests** — Open an issue with the `enhancement` label
- **Pull requests** — Fork the repository, make your changes, and submit a PR

### Development

```bash
# Clone the repository
git clone https://github.com/amiinmaalik/iftin.git

# Move to your WordPress themes directory
mv iftin /path/to/wordpress/wp-content/themes/

# Activate via WordPress Dashboard or WP-CLI
wp theme activate iftin
```

Please follow [WordPress Coding Standards](https://developer.wordpress.org/coding-standards/)
when contributing code.
